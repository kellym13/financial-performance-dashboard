# Financial Performance Dashboard

## Overview

An interactive financial performance dashboard built with Power BI and DAX using financial data from Excel

The dashboard provides a business-focused view of sales, profit, units sold and profit margin across countries, products, customer segments and time periods.

## Key Features

- Total Sales KPI
- Total Profit KPI
- Total Units Sold KPI
- Profit Margin KPI
- Profit by Country
- Sales by Country
- Sales and Profit by Product
- Units Sold by Product
- Profit by Customer Segment
- Profit over Time
- Sales by Month
- Interactive Country filter

## Tools Used

- Power BI
- DAX
- Excel

## Key DAX Measures

- Total Sales
- Total Profit
- Total Units
- Profit Margin

## Project Purpose

The purpose of this project was to practice transforming business data into an interactive dashboard and communicating financial performance through clear, business-focused visualisations.
